[Agent Studio Preview31 — 本机操作确认提醒与超时保护]
- 待确认操作显示在主界面；从任务页面滚动到其他位置时，保留可点击定位的提醒，显示目标电脑、操作内容及剩余确认时间。
- 当前设置弹窗关闭后再定位确认内容，保留正在填写的草稿；定位本身不会批准操作，每项新请求都需重新勾选并明确确认。
- 确认到期后停止等待，过期点击不会发出确认请求，不会自动批准或重放操作。
- 保留公司 HTTPS 证书、内置电脑连接、原签名更新及失败恢复。客户端修复不涉及数据库变更。
- WorkBuddy 完整调研仍须以实际报告和来源验收，启动或截图成功不代表案例完成。

[Agent Studio Preview29 — 公司 HTTPS 开箱即用与统一桌面能力]
- 内置公司 HTTPS 根证书，仅对指定公司工作台 Origin 生效；仍验证证书链、有效期和服务器名称，不关闭 TLS 校验、不改系统证书库。
- 业务 API 网关、内置电脑连接器及应用内更新检查/下载使用同一受限证书信任；签名清单和安装包 SHA-256 校验、失败回滚保持不变。
- 更新后保留账号、电脑授权、连接配置与员工数据；首次安装和后续应用内更新均携带公开 CA 及其指纹配置。
[WorkBuddy 与 Agent 执行可靠性]
- WorkBuddy 已在前台时直接只读观察，不重复请求无动作的激活确认；后台激活和每次输入/点击仍需本人审批。
- 应用启动和窗口列表返回明确授权 App ID、窗口 ID；确认超时、取消、权限与工具错误提供中文诊断，不自动重放不确定副作用。
- 完整保存本机工具回执，重跑 Attempt 使用独立结果标识，避免新旧结果覆盖；运行记录可正确读取评估与反馈。
- Agent 原位重跑、Agent 删除后的任务归档、模型资源统一设置、需求预览错误诊断及幂等恢复均纳入同一版本。
- 窗口视觉操作支持已授权截图定位和单次审批动作；截图变化后旧坐标失效，动作回执不替代业务成果核验。
- 修复部分应用 PrintWindow 截图超时：仅在已授权窗口处于前台且无遮挡时使用备用取图；后台和遮挡状态提供恢复提示，不自动重复输入或发送。
[部署与验收边界]
- 客户端不自动部署 PocketBase/Worker。业务后端需与同一发布提交配套更新，执行 CI、备份、迁移和健康检查后切换。
- 应用任务以实际回复和可核验成果判定完成，启动、输入或点击回执不会被当作业务成果。

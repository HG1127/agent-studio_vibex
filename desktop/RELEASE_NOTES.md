[桌面电脑工作区]
- 顶部统一设备控制栏，集中当前电脑选择、连接状态、暂停/恢复、使用电脑及连接管理。
- 桌面主体聚焦文件与浏览器工作区，移除重复设备信息卡、重复连接按钮和重复说明。
- 设备清单、搜索、刷新与撤销管理收纳至默认折叠入口；保留账号归属、状态核验与授权保护。

[Agent 任务体验]- 修复原位重跑 API 路由注册位置，确保服务端配套 Hooks 中存在 `/api/agent-runs/{id}/retry`。
- 本机执行器最长执行窗口调整为 105 秒，并为服务端 120 秒租约保留 15 秒完成回执余量，覆盖最长 90 秒的本机授权确认窗口。
- 试跑页移除重复的模型选择控件，模型统一在「资源与设置」中选择。
- 失败任务支持在原任务上直接重新运行，保留原任务编号、失败原因及历史 Attempt，不必为每次重试新建任务。
- 试跑页面支持快速选择已验证的模型连接与模型 ID；跨页面恢复与重试后同步实际执行模型，不修改已保存的 Agent 方案。
- 重试前会重新校验 Agent 归属、方案快照、模型连接与请求幂等标识。

[Agent 生命周期与审计]
- 任务与创建它的 Agent 绑定。删除 Agent 时，停止关联中的运行，撤销待执行授权，并将关联任务及历史尝试归档为只读记录。
- 已删除 Agent 的任务不可恢复、重试、继续执行、生成新评估或提交/修改反馈；历史结果与运行报告仍可查看、导出。
- 独立运行详情页与试跑页统一显示归档状态，空评估/反馈数据按未生成状态安全呈现。

[桌面兼容与更新安全]
- 保留 Preview24 的本机连接器、WorkBuddy 应用操作、签名应用内更新、安装文件完整性校验及失败回滚能力。
- 本版本为 Windows x64 预览版，未进行 Windows Authenticode 代码签名。
- 本客户端更新不自动部署 PocketBase/Worker 后端；服务端 API 需配套更新并单独验收。

# PG18 原生语义索引准备

本增量建立 SQL035、员工自己的索引设置、可变维度存储、增量队列、状态和回执接口。它是后续原生语义检索链路的一部分。当前不会调用 Embeddings API，不会运行索引 Worker，也不会将现有关键词搜索标为语义搜索；正式切换仍为 NO-GO。

## 独立启用条件

在隔离空库按顺序应用 SQL032–035，并保持已审阅的原生配置写入及共享开关。设置准备另须两项配置：

```text
AGENT_STUDIO_PG18_EMBEDDING_SETTINGS_UAT_ENABLED=true
AGENT_STUDIO_PG18_EMBEDDING_SETTINGS_UAT_APPROVED=APPROVE_DISPOSABLE_PG18_EMBEDDING_SETTINGS_ONLY
```

该许可仅开放设置和队列准备，不授权模型计费或付费分派。默认关闭；只读计划、预检、root 用户和非 HTTPS 原生站点不能借此开启写入。事务范围每次显式写入 true/false，复用连接不会继承上个事务的能力。

## 设置及数据边界

- 配置引用本人当前启用的 OpenAI 兼容连接、精确连接修订和显式模型名称，不默认选择某个模型或 1536 维。接口只检查当前配置，不表示外部提供商已经接受该模型。
- 索引端点采用独立许可，保留管理员认可的兼容 HTTPS 服务，以及显式许可端口的本机 HTTP 服务。默认只认可 `api.openai.com`。配置沿用 `AGENT_STUDIO_EMBEDDING_ALLOWED_HOSTS`、`AGENT_STUDIO_EMBEDDING_ALLOW_LOOPBACK` 和 `AGENT_STUDIO_EMBEDDING_LOOPBACK_PORTS`；生成执行器的现有地址检查不变。实际计费传输接入后还须在连接前重新校验并固定 DNS/目标地址。
- 新向量表使用不固定维度的 `vector`，边界为 2–3072；旧的 `knowledge_chunks.embedding vector(1536)` 试验列不被复用或授予新角色。3072 维不能套用 vector HNSW 索引；后续检索需使用兼容维度的精确距离或经验证的分区方案。
- `agentstudio_knowledge_embedding` 无登录、继承或角色成员关系。它仅访问必要的模型元数据、知识内容和新私有状态，不能读取密钥封装、认证账户、会话或旧试验向量。API、Worker、凭据 Broker 和租约身份解析角色及其成员登录均不能直接读取新向量表。
- 原生启动验证函数所有者、固定搜索路径、公开执行权限、表 RLS、无固定维度的列和增量触发器。即使设置开关关闭，已有新角色的凭据和向量权限漂移仍会被拒绝。API 仅新增迁移版本标识的只读权限，不读取迁移正文。

## 生命周期及接口

`/api/v2/knowledge-embedding/settings` 提供本人设置读取和显式 configure/disable；`receipt` 按原请求 ID 核对结果。`bases/<id>/status` 和 `rebuild` 仅限知识库所有者。所有写入使用原生 Cookie、CSRF、版本比较和精确请求回执，响应丢失不会自动重发。伪造员工 ID、外来知识库、密钥或向量字段均不能成为操作范围。

首次启用或改变连接、模型、端点时会清除旧向量并按新修订排队；完全相同的配置保留已有索引，避免重复索引费用。禁用清除向量和队列；模型连接被删除时关联状态级联清理。索引计费分派的持久记录须在后续执行模块中独立保留，不能靠删除队列来重试结果不明的付费请求。

直接导入 indexed 文档、旧入口从 processing 变为 indexed、以及片段文本变化都会按所有者既有设置增量入队。共享编辑者导入的内容仍属于原所有者，状态和重建不向读者开放。状态由当前连接修订、内容哈希和维度计算，失效配置不能显示 ready。

配置、重建、禁用与增量写入共同使用所有者事务锁，避免并发导入按旧配置修订重新入队。SQL035 在原内容导入/删除入口外加入同权限封装，先取得所有者锁，再进入原有配额及知识库行锁；原实现不再向 API 直接授权。旧私有知识库写入也先取得所有者锁，避免触发器与父行锁顺序冲突。触发器还锁定当前设置行，防止模型连接删除与入队产生悬空引用。后续计费执行必须先取所有者锁，再锁设置和队列，并在外部请求前结束事务，不能持锁等待模型服务。

## 尚需接入

付费分派防重、独立索引 Worker/Broker、响应后的设置/内容/身份复核、读者自己计费的查询向量、当前共享 ACL 与语义许可、混合检索及关键词回退、员工设置/进度界面、Agent/Workflow 引用集成和完整环境验收仍未完成。本设置准备不能替代这些要求。

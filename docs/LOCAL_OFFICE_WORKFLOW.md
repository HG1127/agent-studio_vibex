# 表格汇总 文档报告 网页录入

本流程用于把员工已授权目录中的 XLSX 或 UTF-8 CSV 台账，按指定分组列汇总金额，生成 Excel 汇总表和 Word 报告，再按需要录入一个已授权的网页表单。所有本地工具继续使用员工设备绑定、逐次审批和已有审计；运行在 PocketBase/SQLite 路径。

## 使用

1. 将台账放入本机执行器已配置的工作目录。原始台账保留；需要日期筛选、公式转值时，先准备明确范围的副本。
2. 在本地执行器 JSON 中增加 `"office": { "enabled": true }`，使用锁文件安装依赖后重启执行器。此功能不需要安装 Word/Excel，生成的标准 DOCX/XLSX 可交给这些软件打开。
3. 打开“诊断与工具调试 → 我的电脑 → 办公流程：表格汇总 → 文档报告 → 网页录入”。选择在线电脑、授权目录，填写源表相对路径、分组列、金额列、报告标题、统计标签、新输出目录。XLSX 多工作表时须填写工作表名。
4. 若要录入网页，填写完整网址，并事先将其来源配置到 `browser.allowedOrigins`。独立浏览器会话不会复用日常浏览器登录；需要登录时由用户完成。
5. 点击“创建办公助手并试跑”。页面只保存本人助手并预填任务、设备，不自动执行。选择模型后启动，核对方案和每次工具参数再批准。
6. 检查输出目录的 `summary.xlsx`、`report.docx`、`summary.json`，以及网页的成功回执。每次重跑换新输出目录；不确定是否提交成功时先核查，不重复提交。

“下载样例台账”提供 5 行合成记录。样例按部门分为销售 1300.00、运营 750.00、研发 450.00，合计 2500.00；不涉及公司数据。

## 工具与数据口径

- `office.table_summary`：读取台账，返回 SHA256、有效记录数、分组金额和合计。按十进制指定小数位转整数后计算，不用模型心算。
- `office.create_report`：同样的来源、列名和小数位参数，加上刚返回的 `expected_sha256`、`title`、`period`、新的 `output_directory`。源摘要不匹配则停止，不创建产物。
- 默认两位小数；工具支持 0–6 位。拒绝多余小数位、空金额、带货币符号或千位分隔符的文本，不擅自清洗或四舍五入。允许负金额作为调整记录。
- 统计标签只是报告标识，不执行日期过滤。所有非空数据行均计入；空行忽略。表头必须唯一、非空，数据列数一致。拒绝公式（包括缓存值）、隐藏行、合并单元格或未明确选择的多工作表。
- 来源上限 2 MiB、5000 行、50 列、50 个分组。金额单值、分组和累计的最小单位绝对值不得超过 10^12。XLSX 解压总量不超过 16 MiB、500 个 ZIP 条目，并在有限内存/时间的 Worker 中解析。
- 输出工作簿保存合计公式及已核对的缓存值；Word 表格和清单直接使用同一份精确结果。源文件 SHA256 存入三个产物，方便追溯。
- 报告目录必须不存在，父目录必须存在。中途停止可能留下部分文件；只有最后写出的 `summary.json` 的 `status: complete` 表示整套文件已写完。已产生的效果不自动重放。
- 网页使用真实页面结构定位，逐项核对后另发提交调用。带自动保存、文件上传、自定义复杂控件或其他隐式副作用的站点应单独适配和验收；该通用模板不承诺适用于任意 ERP 页面。

## 验证

`pnpm check` 包含办公精度和文件回读测试；`pnpm test:e2e:parallel` 包含独立的真实 PocketBase、Playwright MCP、报告文件和网页回执流程。可单独运行 `pnpm test:office-flow`。测试使用独立数据目录和合成数据，不读取公司业务记录。

本机 Word 已以只读方式打开生成报告并导出单页 PDF，检查了中文、表格、金额和分页。真实模型验收结果见[2026-10-26 验收报告](LOCAL_OFFICE_REAL_ACCEPTANCE_20261026.md)；功能测试不能替代具体业务的员工 UAT。

实现采用 [ExcelJS](https://github.com/exceljs/exceljs) 与 [docx](https://docx.js.org/)，均固定于锁文件。本地管理员应使用 `pnpm install --frozen-lockfile` 安装执行器依赖。

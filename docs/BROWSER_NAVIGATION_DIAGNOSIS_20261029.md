# 浏览器 about:blank 排查与体验修复

日期：2026-10-29；项目：Agent Studio 独立工作台；范围：本机连接器和浏览器工作区。不是生产部署。

## 已核实原因

对持久预览数据库进行只读查询，设备 `zhouqing #9xvoJI` 在 2026-10-29 16:11:05（新加坡时间）对应的任务是 `browser.browser_snapshot`，不是 `browser.browser_navigate`。该回执显示 `Page URL: about:blank` 和空页面结构。该设备此前 15:54–15:55 的四次浏览器操作也都是读取空白页；查询范围内没有提交打开网址的导航任务。

旧版“读取当前网页”会使 Playwright MCP 初始化浏览器并创建空页，工具随后正常返回空快照。工作台将工具成功笼统显示为“真实检查完成”，没有指出“没有打开目标网址”。因此截图中的空白窗口不是已有证据证明的网站加载白屏，而是未导航的独立浏览器页面；旧界面的操作含义与结果反馈不够清楚。

另一个独立问题：本机 hosts 已配置 `192.168.1.133 aios-staging.test`，本机解析结果确实是 `192.168.1.133`。直接访问 `http://aios-staging.test` 返回 HTTP 200，但标题为“恭喜，站点创建成功！”，内容是默认站点首页。此次不是 DNS 不解析；即使导航成功，该地址当前仍不是业务应用页面。没有修改 hosts、DNS、宝塔站点或网站部署。

## 修复内容

1. 主按钮改为“打开目标网页”；“读取当前网页”明确只读取受控页面，不访问输入框中的地址。填入网址本身不执行任何请求。
2. 工作台区分目标网址与上次回执中的实际网址。空白页、无网址回执、默认站点、HTTP 错误页均不能显示成业务网页已打开。
3. 在操作区显示“等待批准 → 提交 → 等待连接器 → 执行 → 已取得实际结果/失败”，包含等待秒数；队列和运行阶段不再因 busy 状态提前结束而丢失进度。
4. DNS、拒绝连接、TLS、超时、未授权跳转及页面关闭分别给出提示；保留安全的机器错误码，不输出请求凭据或原始网络堆栈。
5. preview.13 连接器阻止尚未导航时的快照/截图请求，不再因为“读取当前页”新建空白 Chrome。
6. 实际网址和页面标题随经校验的回执返回。未授权的资源/重定向在发出请求前被拦截，不自动扩权。
7. 修复 Chromium 错误页延迟提交打断下一次访问的竞态；失败先收尾，不自动重放请求。主动关闭浏览器后，下一次明确导航重建专用 MCP 会话，不复用失效标签句柄。
8. 移除旧版异步 setContent 注入的假诊断页面，避免诊断页覆盖后来成功访问的真实网站。
9. 取消后重新读取服务端任务状态，而不是无条件把界面写成“已取消”；已经发出的网页请求不保证能撤销。
10. 页面正文和截图在工作台内显示。独立 Chrome 仍是实际执行/登录窗口，不是网页内嵌的完整远程桌面。

# PG18 公司运行统计候选

公司概览仅供每次读取时仍有效的 Native 管理员查看。浏览器能力标记用于显示入口；身份与权限由真实 Cookie、当前员工/账号状态和数据库投影重新验证。两条固定 GET 分别返回公司总数与员工当前页，均不提供任务内容、会话、邮箱、凭据、执行动作或原任务链接。

- 可选迁移 `pg_v9_061_company_overview.sql` 独立于默认 fresh050。当前工具不代表已支持060/061受控安装，未对真实目标执行初始化。

- 当前Native管理员资格在每条SQL投影语句内检查。撤权发生在投影快照之前必须拒绝；快照已取得后最多完成该次有界读取。现有Cookie已验证后的撤销窗口按原协议保留。
- 全局覆盖全部已存在Native账号，包含已停用员工的实际计数，排除非Native及缺失账号。UUID游标每页1–20人；公司和员工页各有独立统计时点，不能从当前页推算公司总数。
- 近七日失败使用包含边界，超期计划为严格超过60秒；仅统计已持久化运行。读取不领取任务、不启动Worker、不调用模型或工具。

## 页面与会话

当前管理员及已安装能力同时满足才显示入口。公司API和状态按员工/API对象绑定，隐藏、退出、切换员工、能力丢失及权限拒绝时清空；迟到旧响应不能恢复旧数据。公司403清除公司视图并保留个人工作台，401使用原员工作用域的过期回调。加载/失败显示未知，真实零值才显示0。

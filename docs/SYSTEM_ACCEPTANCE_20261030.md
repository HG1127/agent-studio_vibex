# Agent Studio 本地系统验收与修复

验收范围：独立 PocketBase 0.40.5 / SQLite + Node Worker 桌面候选，桌面 preview.9、连接器 preview.19。保留现有员工页面、账号隔离、角色授权、审批和运行快照。未部署服务器，未切换 PostgreSQL，未改动生产数据库。

## 修复结果

- 用户原始需求明确禁止的资源，不再因模型建议或旧选择而自动加入。标为只读但名称或说明含发送、删除等动作的工具，不再自动当作只读能力匹配；这只是规划检查，运行授权仍在后端执行。
- 具体 MCP 工具替换同名通用别名，避免保存后残留不可执行名称。能力类别依据真实工具名判断，连接的显示标题不再误导分类。
- 模型连接核验未完成时，生成按钮显示原因并等待就绪，避免点击后只提示错误而没有生成。
- 创建向导第三步可以选择本人电脑，识别具体应用、操作和截图权限，点击选用后仅给指定角色分配本机能力，并将设备带入试跑。模型不能自动授予角色权限。
- Codex 只读与写任务分别检查；写任务同时需要应用和工作目录授权。文件新建权限不能替代编辑、恢复等具体权限。
- 调度预检识别本机应用和 Codex 任务，避免仅凭全局启动工具判断任意应用可用；发送等操作仍需本人确认。
- 默认单元测试改为自动收集全部根级测试文件，补上原先遗漏的 12 份测试；失败批次不能被后续成功掩盖。完整创建和常规员工交互已加入正式端到端入口。
- 补齐三个控件的可访问名称，修正定时计划编辑焦点，并排除构建临时资源触发的开发页面重载。

## 使用与验证边界

完整退出旧版本（托盘菜单“退出并停止本机连接”），运行 preview.9 安装包并选择安装目录。原账号、服务器和设备授权仍从原用户配置读取；不会因为更新自动扩大权限。首次连接、后续电脑选择、长期应用授权及逐次操作确认均在主软件内完成。

测试使用临时员工、临时数据库、本地确定性模型和专用测试程序。没有发起真实付费 Codex 任务，没有发送真实微信消息，也没有对真实业务数据进行员工 UAT。通用应用控制依赖软件暴露 Windows 控件，特殊画布或管理员窗口可能需要专用适配。安装包仍为未签名预览版本。

本记录不能视为 PostgreSQL 迁移验收或生产切换批准；相关工作仍由独立迁移验证与原有发布门禁处理。发布包的 `acceptance.json`、`SHA256SUMS.txt` 和最终通过日志记录确切源码提交与文件摘要。

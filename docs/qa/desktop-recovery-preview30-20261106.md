## 改动与边界

- 同路径同版本第二次启动静默退出，由主实例恢复并聚焦原窗口；只有经过校验的锁元数据能证明版本/位置冲突时才提示。旧实例没有元数据时只唤起，不虚构旧版信息；更新中启动屏障继续生效。
- 视觉动作的截图凭据在进入 native 输入调用之前失效，返回 `accepted:false / effectState:not_started / status:needs_observation`。这不是成功动作，也不发出输入；Agent 先重新观察，再核对新动作和审批。拒绝、取消仍停止；任何 native 调用之后的未知失败都不进入此恢复路径。
- 已接受的视觉动作返回独立回执，界面标记“已执行 · 待核对”，不能等同业务任务完成。后续截图失败只允许观察核对，不重复输入或发送。
- 后端执行计划排除未执行、畸形或不确定的视觉回执；兼容旧版明确 `accepted:true` 的视觉动作。既有重跑历史副作用检查不放宽。
- 离线模型检查改为自然退出，修复 Windows Node 在 TypeScript 加载线程尚未收尾时直接退出导致的 libuv 断言；未配置模型的检查仍为零调用，真实模式仍拒绝缺少凭据和确认的请求。

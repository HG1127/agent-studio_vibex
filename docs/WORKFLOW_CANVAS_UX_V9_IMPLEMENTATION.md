# Agent Studio 独立版｜工作流编排 UI/UX 增强与验收

> 适用范围：`agent_studio_vibex版本` 独立 React / PocketBase 运行链路。与 V8/V9 PostgreSQL 隔离迁移无关。本文记录已编写源码及待验证边界，不代表正式生产部署或发布成功。

## 本次设计与实现

保留当前独立员工登录、Worker、知识库和授权边界，不从上传 ZIP 覆盖后端。增强现有 React Flow 编辑器：

- 双击空白画布、工具栏“+”添加节点；从出口拖到空白处后选择节点类型，创建节点和连线在同一图更新与撤销记录中完成，先验证端口占用与 40 节点上限。
- 节点/空白右键操作；同一画布内的复制、粘贴、创建副本、多选删除、对齐与等距分布、Ctrl/Cmd+Z/Y/S；快捷键仅在画布上下文生效，不覆盖其他页面的浏览器复制/全选。
- 仅“空白或一个开始节点”的工作流展示基础问答和条件分支示例。示例需重新选模型后才能正式运行。
- 工作流 JSON v1 格式导入导出：512KB / 40 节点 / 240 连线，校验唯一节点 ID/标题、合法端口/连线、循环体、非循环环路；导入到新的工作流，重新生成节点与连线 ID。
- 便携 JSON *不会继承* 用户/公司账号、模型、Agent、知识库或外部工具绑定；导入工具节点保持未绑定，必须显式重新选择授权工具。提示词、参数模板等文本可能包含用户手写的敏感数据，导出前有确认提醒；这不能替代资料脱敏与公司分享审批。
- 编辑节点标题时同步修改其他节点的 `{{旧标题.output}}` 与 `ref_title`；复制粘贴内部关联时同步改写。
- 运行前检查面板对缺少配置、断开的节点、未连接的条件出口、循环回边、异常变量等分级提醒；草稿可保存，运行阻断错误需解决。
- 解决旧版本拖拽结束位置的历史快照时序、快速撤销/重做和保存期间再次修改后错误清除 dirty 状态的问题；窄屏优先画布，宽屏三列布局改到 `xl` 起生效。
- 节点沙盒：本地模拟 `{{input}}`、上游 `{{节点标题.output}}`、模型/Agent 提示词、工具 JSON 入参、条件文本/数值判断、循环列表与结束输出。允许录入样本和选用当前用户已查看的本工作流运行结果；不触发 LLM、工具或写操作。循环体内提供 `loop.item` / `loop.index` 样本；类型提示不等于完整运行时 Schema。
- “点击插入变量”只建议沿当前连接路径可到达的上游输出，减少无效自引用；静态检查提示不确定的引用、循环变量超出作用域以及非法分支。
- 独立账号单次会话验证：全局路由、登录页、员工账号菜单不再并发调用 PocketBase `authRefresh`。认证失败与暂时的网络/请求取消错误分开；后者保留凭据、提供重试入口；不绕过服务器身份校验。
- React Hooks 中原有的 4 项同步 Effect 警告已通过改造初始化、取消过时 GET 请求和定时器语义修复；工作流相关文件按定向 ESLint 进行质量检查。
- 全屏移动端侧抽屉增加明确关闭按钮、背景遮罩以及左右面板互斥；移动触控按钮扩大操作面积。
- 为自动创建的示例工作流补充节点测量后的画布自适应；最小缩放由 0.4 降至 0.2，改善多节点流程的一屏总览。
- 节点真实模型试运行（**明确用户动作后才调用**）：在免费本地沙盒之下，模型节点可以选择已启用的员工私有连接，显示费用警示并经确认后单次发送渲染提示词。请求体强制 `strict_model=true`、输出 `max_tokens=512`，不带工具/Agent；服务器对模型连接归属和当前允许的模型二次验证，拒绝失效模型而非悄然选择默认模型。结果在 `llm_jobs` 中按用户与 `request_id` 保存，可点击查询；超时不自动重复调用。
- 无论是空画布还是节点配置/多选状态，顶部始终保留「保存工作流」按钮，并根据编辑状态禁用或启用；草稿修改后刷新/关闭页面触发浏览器原生未保存警告，保存成功后自动解除。
- 单节点真实模型调试的限制进一步由后端强制执行：必须指定已有员工身份下授权的模型连接与模型、明确使用 `strict_model=true`、单条不超过 8000 字符的用户提示词、整数 16–512 的输出 token 上限，以及合法请求编号。拒绝无效请求且不访问供应商；同一请求编号的已完成结果缓存返回，执行中只可查询，不能重复触发。
- 对 OpenAI 兼容接口，真实节点调试禁用空响应时的自动增额重试；对 Gemini 显式设置 `generationConfig.maxOutputTokens=512`（实际值随本次允许的 ≤512 tokens 限额），防止前端限额在供应商协议层失效。原有非调试 Agent/Workflow 行为保持不变。
- 新增统一的连线规则与拒绝原因：常规节点不能形成非法环，条件/循环出口只能占用一次；从循环体可达的节点允许连回该循环节点，但 `done` 退出分支不能错误地回到循环头。对拖到目标节点却被拒绝的操作展示具体原因，不再只提示“连线不合法”。
- 快速新建节点会查找邻近空白位置，避免连续新增的节点压在同一块区域；删除节点和连线同时更新画布 React 状态与同步引用，防止“删完立即保存”保存了旧图。
- Chrome 扩展覆盖 Shift 拖动矩形框选、Shift 点击多选、左对齐与垂直等距分布（含撤销/重做）、合法循环回边与非法退出回边、故意延迟 PATCH 后再次修改、模拟 HTTP 503 保存失败和重试。慢网络时只有旧快照已落库，新内容继续显示未保存；503 不清空输入。
- 身份安全核查：旧 LLM 处理器仍以内部 `rh_user_id` 字段存储所有者，但独立登录的全局 `routerUse` 会丢弃未验证的客户端 `X-Rh-User-Id`，并从 PocketBase 已验证的 `studio_users` JWT 重新注入身份。本轮为 `/api/llm/models`、`/api/llm/chat`、`/api/llm/poll` 添加伪造请求头但无 JWT 必须得到 401 的独立集成用例。不要为了改字段名而破坏已有身份中间件。

## 验收命令

```bash
pnpm test:workflow-graph
pnpm test
pnpm build
pnpm test:e2e:parallel
pnpm test:model-provider  # 模拟 OpenAI/Anthropic/Gemini + 模型节点严格授权
# 可选：真实 Chrome/Edge 工作流 UI 冒烟测试（无需安装 Playwright）
node --test tests/workflow-ui.chrome.mjs
```

不要将 `pnpm check` 单次因 Windows Node 内存耗尽误判为 TypeScript 源码错误：必要时分别运行 `pnpm test` 和 `pnpm build`。定向 `eslint` 可检查本轮改动；全仓 `pnpm lint` 需要针对其他页面独立验收，不应由局部验证推断整体通过。Chrome 冒烟测试需要安装 Chrome 或 Edge、本地 PocketBase 测试二进制及 Node WebSocket，使用全新临时数据库与随机员工测试密钥，并在退出后清理。可设置 `AGENT_STUDIO_UI_CHROME_BIN` 指定浏览器。

## 浏览器 UI 验收范围与剩余清单

已实现的 Chrome CDP 冒烟测试覆盖：独立员工账号登录（真实 JWT，无身份伪造）、路由加载、初始开始节点、基础问答示例、双击节点与本地沙盒、双击空白添加、**真实鼠标拖线建节点 + 自动连接 + 原子撤销/重做**、节点右键复制与空白右键粘贴、**条件节点 true/false 与循环节点 body/done 双出口真实拖线**、Shift 键多选三节点与真实左对齐、顶部保存按钮、浏览器原生草稿防丢失提示、**11 节点/7 连线保存并刷新完整恢复**、JSON 脱敏导出和独立导入、无效版本导入拒绝（不创建额外记录）、768px 平板及 390px 移动视口不横向溢出、全屏侧边抽屉打开/关闭。还使用同一隔离环境的 **本地模拟模型服务** 验证真实模型节点的费用确认、一次请求返回、请求编号查询与不重复调用。测试显式检查登录后不出现 401，也不产生被取消的重复认证刷新。Chrome 测试**从不访问付费模型**。**这些只代表特定路径的浏览器验收，并非完整 UAT。**

仍需补充以下回归场景：

1. 条件/循环出口重复占用及其他非法边（自环、非法普通环）在真实画布的负向交互，以及合法循环回边的**真实 Worker 执行**；连接规则已有单测、循环回边与退出回边已有浏览器测试。
2. 多选节点批量**水平**等距分布、复杂布局反复编辑与其他页面/文本输入框的快捷键作用域；Shift 框选、点击多选、左对齐和垂直等距已通过。
3. 极端慢网络、浏览器离线/掉线后的工作流恢复、跨页面切换与工作流分享权限的真实浏览器回归；延迟保存、HTTP 503 保留草稿/重试、JSON 非法版本和安全导入导出已覆盖。
4. 真机移动端多指缩放、水平/垂直手势、触控长按菜单、抽屉焦点/键盘无障碍验证；Chrome 390px/768px 模拟不能代表真机。
5. 模型节点真实网络超时、员工撤权、供应商异常的浏览器级复核，模型账本成本对账，以及长期任务运行观察。

## 尚未宣告完成的部分

- 节点沙盒的免费部分仅在本地解析输入；另外新增的真实试运行**仅支持模型节点**且需要明确确认，使用已有员工权限、模型调用路由和 `llm_jobs` 账本。真实付费 API 未在本轮调用；外部工具/Agent 单节点执行、断点恢复、类型化变量 Schema 及完整生产审计展示仍属后续。
- 页面内复制粘贴是会话本地剪贴板，不承诺浏览器系统剪贴板跨标签、跨员工支持。
- Chrome 的移动端模拟不能替代真机触控及全部屏幕宽度验收。
- 跨用户受控工作流共享、长期任务可恢复执行和正式 PostgreSQL 切换仍是后续工作。
- PostgreSQL 17/pgvector 保持隔离试验与生产 **NO-GO** 边界；任何正式数据迁移须按现有审批、备份、对账、UAT 和回滚验收流程独立推进。

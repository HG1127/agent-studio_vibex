# PG18 共享知识库运行时候选

本候选沿用空库初始化方案，旧测试数据无需导入。它扩展 SQL032/033 的员工共享入口，加入 SQL034、Agent/Workflow 资源校验和有界关键词引用。默认关闭，尚不代表正式切换 GO。

## 启用边界

按顺序审阅并应用 `pg_v9_032`、`pg_v9_033`、`pg_v9_034`。共享能力仍须显式设置现有两项配置：

```text
AGENT_STUDIO_PG18_KNOWLEDGE_SHARING_UAT_ENABLED=true
AGENT_STUDIO_PG18_KNOWLEDGE_SHARING_UAT_APPROVED=APPROVE_DISPOSABLE_PG18_KNOWLEDGE_SHARING_ONLY
```

Native API、私有 Dispatch Broker，以及参与处理任务的 Prepare、Model、Workflow V2、Autonomous Worker 使用相同的已审阅共享配置。各自的登录、mTLS、执行授权和模型费用审批仍独立生效。开启共享时，启动只读预检必须验证 SQL034 两个 API 专属函数的所有者、固定搜索路径和执行权限；缺少函数或权限漂移会拒绝启动。SQL034 不授予 Worker、凭据 Broker 或身份解析登录共享内容读取权。

共享范围由服务组合层设置到业务连接池，事务开始后以 `SET LOCAL` 写入上下文；请求体不能选择此能力。未启用的连接池显式写入 false，连接复用不会继承上个事务的共享范围。验证过的当前员工身份仍决定 `agentstudio.actor_id()`。

## 员工和执行行为

- Agent 可绑定最多三个本人或当前获授权的知识库。Workflow 知识库工具使用同一选择列表。不可用的旧引用会显示为可移除项，不会悄悄换成其他知识库。
- 保存 Agent、保存 Workflow、提交共享任务、重放运行快照和每次步骤分派重新确认当前权限。Workflow 会检查所有绑定的 Agent，包含已经完成的节点，防止后续步骤继续发送被撤销知识库的旧引用。
- 模型、HTTP、MCP、摘要和网页工具在实际执行适配器之前再次检查当前快照及权限。单次分派标记先提交；之后发生拒绝或结果不明时暂停并保留核对记录，不自动重发。
- 共享知识库的模型调用使用读者自己的模型连接及密钥。旧的无绑定固定模型路径不能生成包含共享知识库的任务；不会借用知识库所有者的凭据。
- 引用只含有界的文件名、文档 ID、片段编号和纯文本。每库最多两个片段，每片段最多 300 个 Unicode 码点。修复了合法 emoji 片段因 UTF-16 长度超过阈值而被拒绝的问题。

权限检查以数据库语句及最终外部调用前的当前读取为准；不在网络请求期间持有数据库事务。撤销不能收回此前已经读取、已经发送的内容，历史记录保留原有员工访问范围。

## 验证与剩余工作

新增隔离用例覆盖：事务范围复用、身份错配、撤销和停用、函数权限漂移、本人计费、无绑定拒绝、Unicode 引用、失效引用清理，以及加载凭据后撤销时零模型调用。使用合成 SQL 和一次性私有 mTLS，无真实模型费用。真实 PG18 TCP 与员工浏览器验证由迁移分支 CI 执行，只有对应提交通过后才算验收证据。

共享运行时是关键词检索。维度兼容的语义索引/检索、调度和协作等旧功能对齐仍须完成；真实员工 UAT、网络与权限审查、长时间 Worker、备份恢复和回滚签收也仍是正式迁移门槛。不能用本候选通过测试来替代这些条件。

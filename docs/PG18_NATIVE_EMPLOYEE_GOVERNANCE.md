# 原生员工账号治理（047 隔离候选）

更新：2026-10-26。PocketBase 仍是当前运行环境，正式切换 NO-GO。
本候选尚待精确提交的实际 PG18、浏览器和综合质量验收。

047 在认证专用 schema 内新增账号治理版本、内部 Agent 模板共享开关和私有审计回执。
管理员可创建管理员或普通员工，修改角色、启用状态及模板分享开关。
普通员工只能修改自己的密码。浏览器身份只来自 Native Cookie；所有操作在认证专用
连接中重新验证当前会话与管理员资格，普通 API、Worker、协作及知识辅助角色不获得
密码、会话、治理回执或新增认证字段的读取权限。

管理员修改使用完整目标状态、预期版本及原请求 UUID，并需明确确认。事务内串行化
管理员变更，禁止停用或降级本人管理员，保留至少一名有效管理员。更新、撤销目标旧
会话、审计和回执同事务提交；相同请求仅返回原结果，冲突请求或过期版本被拒绝。
只读确认接口只读取已有回执，在配置写入关闭后仍可核对，不能创建修改。

停用同时更改账号 enabled 与员工 status，以沿用本人任务、知识权限和来源校验中的
现有有效员工检查。角色或启用状态变化撤销目标全部旧会话；重新启用不恢复已撤销
会话。停用不能撤回已发送的外部调用，未知结果继续遵守原执行链的不重发规则。
重新启用后已有业务配置和授权仍按各自的版本、期限及来源检查；本接口不隐式清空
员工的私人配置。未来委托审批须另外验证经理当前身份、授权期限与固定操作来源。

共享开关的旧参照是 `internal_templates.pb.js` 的内部 Agent 模板分享资格。
关闭它不会停用私人知识、本人任务或既有安全描述协作。完整内部模板原生路径尚待
实现；届时必须消费此资格，不能因本开关已落库就认定模板迁移完成。

本人改密验证旧密码、执行受限密码 KDF，拒绝相同密码，并在同一事务更新密码和
撤销全部本人会话。响应清除 Cookie，界面销毁员工私有状态并要求重新登录。
审计仅保存操作、实际操作者、目标及权限状态，不保存密码、KDF 结果或会话摘要。
创建或改密的响应不明时，界面要求核对账号或重新登录，不自动重发凭据。

启动及新库检查会核对专用角色、用户状态列授权、私有回执的 FORCE RLS、策略、
认证新增字段及跨角色授权；配置写入关闭时仍执行这些检查。

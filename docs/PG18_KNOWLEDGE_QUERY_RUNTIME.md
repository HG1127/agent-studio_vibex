# PG18 读者语义与混合查询

SQL038 在 SQL032–037 之上提供独立查询运行时。它复用所有者已有索引，使用读者本人当前的 Embedding 配置和密钥，只将查询文本发送给提供商。共享文档文本和原始向量不会发送给读者的 Embedding 提供商。员工查询界面见[语义设置与查询界面](PG18_KNOWLEDGE_SEMANTIC_UI.md)；Agent/Workflow 的语义调用尚未接入，正式迁移仍为 NO-GO。

## 启动与费用

查询执行须单独设置以下隔离运行批准；该批准不会启动所有者索引：

```text
AGENT_STUDIO_PG18_KNOWLEDGE_QUERY_UAT_ENABLED=true
AGENT_STUDIO_PG18_KNOWLEDGE_QUERY_UAT_APPROVED=APPROVE_DISPOSABLE_PG18_READER_EMBEDDING_QUERY_UAT
```

Native API 还须已有配置写入、知识共享、Embedding 设置和授权记录许可，并满足监听 HTTPS、非 root 的启动约束。私有服务要求共享许可，使用现有独立索引 Worker/Broker 登录和凭据目录。两个执行功能可分别批准。默认、离线计划和只读预检均不领取任务或调用提供商；示例服务仍是只读预检模板。

读者先为本人当前配置显式授予查询费用授权，再经 Cookie/CSRF 提交 `POST /api/v2/knowledge-query/submit`。每个付费请求仍须绑定精确配置 UUID、配置修订、授权修订和 `PAY_ONCE_FOR_THIS_READER_QUERY`。请求只接受查询、知识库范围、模式、数量及上述确认；拒绝任意所有者、URL、密钥或向量覆盖。

查询最多 300 个 UTF-16 单元、10 个知识库、8 条结果。显式 semantic/hybrid 必须满足当前共享语义授权、兼容模型端点和已有索引；auto 未逐次确认时执行免费关键词查询。auto 的缺配置、未授权、未索引和提供商失败均返回明确降级原因；严格语义模式失败时返回不明状态，不静默降级。发生提供商错误后的关键词结果仍标记可能已计费。

## 防重与当前权限

每个读者和请求 UUID 只有一条记录。请求正文改变会产生冲突。Broker 在读密钥和网络请求之前提交分派记录，之后重新核对读者身份、配置、共享修订和租约；返回后再核对。已经分派的失败或失联请求不自动重放，GET 回执也不会增加费用。领取但未分派的过期准备任务可换令牌领取。

`GET /api/v2/knowledge-query/receipt?request_id=...` 仅供本人恢复请求状态。每次读取都重新核对当前权限、共享修订、内容哈希和向量更新时间；撤权后重新授权不能恢复旧结果。查询正文、范围快照和结果引用在 15 分钟后停止提供，Worker 下一次清理最多清除 32 条过期载荷，保留防重摘要和计费记录。物理删除依赖 Worker 清理继续运行。

Worker 只接收封存的任务标识与租约，私有 mTLS 返回值只有 `retrieved` 状态。片段、密钥和向量均不通过该通道。独立 NOLOGIN SQL 辅助角色拥有固定 search_path 的封装函数；权限预检拒绝直接表授权、PUBLIC 执行、丢失强制 RLS 或防重唯一约束等漂移。

## 检索与验证范围

关键词支持英文词和中文双字词，按库最多扫描 1600 个候选；语义最多扫描 700 个候选，以当前内容哈希和配置修订匹配所有者缓存，先判断维度再计算余弦距离。混合模式合并关键词及语义排名，返回候选截断提示。保留 2–3072 维，不新增固定 1536 维约束或不支持 3072 维的 HNSW 索引。

只读 API 审查包自动包含查询依赖；`--with-knowledge-index` 还包含同时支持索引和查询的私有服务闭包及两个只读模板。生成包不含数据库、凭据、依赖二进制或自动 SQL 初始化。

隔离验证覆盖本人密钥、共享授权、回执重放、计费失败、TTL、维度、权限漂移、真实 mTLS 和 Cookie/CSRF。真实 PostgreSQL 18 验证仅在指定 GitHub 临时环境执行，提供商为合成实现。最终通过数量与精确提交以迁移验收记录为准。真实员工 UAT、长期 Worker、备份恢复、回滚演练及功能对齐仍须完成。

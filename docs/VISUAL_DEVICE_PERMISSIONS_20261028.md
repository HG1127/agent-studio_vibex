# 网站与文件可视化授权 — 2026-10-28

## 使用入口

独立 Windows x64 连接器升级为 `0.1.0-preview.3`。完整解压便携包，双击 `Start-Connector.cmd` 打开本机管理页。在「我的已保存连接」中选中自己的设备，点击「管理授权」。账号绑定和设备凭据不需要重新生成。

工作台设备页展示最近上报的网站与文件范围，并给出本机图形入口指引；不接受远程网页提交的任意本机路径。不扫描整盘，不把本机管理会话、设备令牌或完整路径写入云端目录清单。

## 修改网站

在「网站」页签输入一个网站或页面地址，点击「添加网站」。地址按协议、域名、端口归一为整站来源；原有网站可以逐项移除。子域名、不同端口和登录跳转所需域名分别授权。不接受通配符、内嵌账号密码、查询令牌。最多 12 个明确来源，空列表将关闭浏览器能力。

以上操作先写入本机草稿。连接运行中可编辑草稿，但不能保存；使用同一窗口的「停止此连接后修改授权」，核对任务中断影响，确认停止后再保存。保存成功后在设备卡片点击「恢复连接」。不要求 PowerShell、JSON 编辑或重新配对。不会修改系统默认浏览器，也不复制日常 Chrome 的 Cookie。

## 授权文件与文件夹

「文件与文件夹」提供「选择单个文件」「添加工作文件夹」。两者调用本机系统选择窗口，不要求用户输入完整路径。每项都可移除，最多 20 项。

- 单文件权限：仅允许读取选中的文件。父目录和同目录的其他文件不自动开放；文件列表只检查这一文件，不枚举邻居。无覆盖写入能力。
- 文件夹权限：默认只读；需要输出文件时，明确选择允许新建。已有同名文件不覆盖。
- 多项权限并存时，整目录授权覆盖其中的文件。若目标是只读一个文件，需要移除覆盖它的整目录授权，界面会提示实际重叠。
- 空文件授权列表关闭文件与办公工具；删除授权项不会删除磁盘文件。

首次连接也提供「只授权一个文件」，无需先开放整目录再缩减。

允许授权不等于所有格式都能以文本方式打开。现有 `files.read` 是 64 KiB 以内 UTF-8 文本预览，PDF/Word/Excel 仍应走已支持的资料或办公流程。

## 安全与一致性

本机管理 API 保留精确回环 Host、Origin 和随机会话令牌校验，不开放跨域 CORS，不提供任意命令执行。新设备连接草稿、原有目录快捷设置和权限管理草稿分别绑定目标设备，不互相转移。

保存需要本机确认、配置指纹一致和运行锁释放。凭据文件不读写，不改变设备身份。每次保存生成新的授权版本及目录别名；服务端从认证设备的工具目录获取授权版本并写入任务，不信任调用方伪造的版本。连接器在执行前核对版本，旧授权排队任务失败关闭，不能借新增权限自动执行。

新增能力依赖本轮新版服务端 `pocketbase/pb_hooks/modules/local_devices.js` 与新版连接器配套。旧服务端未带授权版本时，修改过权限的连接器会明确拒绝执行，而非降级绕过检查。需要管理员按正常流程加载新版后端；不要为升级而重建已有数据库。

## 更新

已解压的旧程序包不会因网页刷新自动更新。先在图形界面停止本程序启动的连接，确认无任务需要继续，再关闭旧连接器并将新版完整解压到新目录运行；沿用当前 OS 用户下已保存连接，恢复即可。不要删除用户目录中的设备配置或转发账号连接文件。

Source implementation only. Root must run the actual Linux/mTLS/process tests.
No local application, SQL, browser or Worker execution is acceptance evidence.

The canonical API is pg18-full069-final-companions.mjs and the five exports in

clock, source-root/entry override or a positive preflight does not open a handle.
The genuine final store must already be open in the parent. Every operation
rechecks the protected final/base/source/runtime/profile/credential bindings.

The exact five remain Bound Broker, Knowledge Broker, Review Broker with
Design, F05 Worker and F05 Broker. Commands, unit names, origin, roles, Design
and exact credential mount leaves stay original. The fixed Root-reserved

remain outside every original128 Writer UID, Native/seven process UID and

Actual root-owned /etc/passwd and /etc/group must have no account UID, account
primary GID or group GID collision. Every kernel scan also rejects unrelated
processes holding a reserved UID, GID or supplementary group. No kind, Writer boot
slot, original seven entry, sample budget or86400000ms minimum is changed.

For each protected UID, bootstrap must install filter OUTPUT rules before
signing the original global network policy hash: an exact owner jump to
ASFC<uid> ahead of any possibly matching broad rule. IPv4 chain accepts
ESTABLISHED,RELATED, then only127.0.0.1 TCP5333 and, for F05 Worker only, its

has only REJECT/icmp6-port-unreachable. C reads actual iptables-save and
ip6tables-save and rejects extra ports/accepts/ambiguous ranges. It never changes
signed firewall policy. This prevents provider/DNS egress during qualification.

Each initial companion-ID.json is written once via B's O_EXCL/fsync record
writer before any child launch. It binds protected run/final profile/source,
exact spec digest, parentPID/start/mount namespace and a private channel nonce.

then uses setpriv with clear groups, no-new-privs and all capability sets empty.
The application has pipe stdout/stderr only, no IPC. Parent validates current
kernel PID/start/PPID/UID/GID/groups/argv/caps/no-new-privs/private namespace.
Paused, dead/reused, wrong-parent or drifted processes do not count as ready.

All five original nonroot preflights are executed again. Their exact stdout
bytes (original JSON plus LF) must match the protected raw preflight file and
SHA, actual application/supervisor exits must be zero, and C checks each exact
original report ABI. Bound/Knowledge key reads are preserved. Review/Design
and F05 preflights preserve their metadata-only key behavior. Expected report

Startup launches F05 Broker before its Worker, preserving the fixed output
order used by B. Every Broker must own exactly its loopback listening socket.
Before launch and at every stable boundary, the private supervisor reads the
actual SHA-bound public certificate mount bytes and checks the effective client
configuration in both directions. Model uses its explicit BOUND_DISPATCH_ORIGIN
and server pin; active original Workflow V2/Autonomous clients use original
fixed7453 origin, their own server pin/certificate and the distinct Broker
WORKFLOW_V2/AUTONOMOUS client pin. Their enabled Model/Tool handlers must exist

Preflight is provenance and is never substituted for current readiness.

# Agent Studio 本地连接器 preview.12：交付与验收

日期：2026-10-29。范围：独立 Agent Studio 工作树中的电脑连接器与工作台文件工作区；不是生产部署。原有工作树改动、员工账号、设备绑定及文件授权均保留。

## 日常操作入口

工作台：`http://127.0.0.1:8180/tool-hub?view=devices`（仅工作台所在电脑）。进入“工具与连接 → 执行资源中心 → 我的电脑”，选中设备后，在“文件工作区 / 浏览器 / 授权管理 / 办公与 Agent”之间切换。

文件列表、文本预览与编辑、修改前后对照、新建、复制、移动/重命名、移入可恢复回收区、恢复及操作回执均在工作台内。Word、PDF 等文件使用“用电脑软件打开”时，软件窗口在被连接电脑出现，不是把桌面软件嵌入网页。

## 连接器启动

- `Start-Connector.cmd` 是日常入口。仅有一条完整可核验的已保存连接时，尝试恢复该连接；只有收到实际执行器在线状态后才不弹出独立管理窗口。
- 首次配对、多条连接、不可完整读取连接列表、恢复失败或未能确认在线时，打开本机设置。没有把“进程已启动”当成“服务器已确认在线”。
- `Manage-Connector.cmd` 是显式打开本机设置的入口；并非第二套工作台。避免在旧连接器仍运行时再启动重复实例。
- 本机选择目录与文件、首次配对及权限提升保留本人确认，不通过 iframe、任意路径输入或模型工具绕过确认。
- 关闭管理网页不等于关闭执行器；关闭连接器进程会离线。未安装开机自启或系统服务。
- 更新程序不会自动开启编辑、移动、删除和打开权限。已配对设备沿用原身份，不应再次创建同名设备或导入过期配对文件。

## 权限与安全边界

“授权管理 → 文件与文件夹”中可以选择具体范围，并单独设置新建/复制、编辑、移动/重命名、可恢复删除/恢复、打开/定位。只读或单文件授权不会扩展到相邻文件。

编辑校验原文件摘要；版本冲突时拒绝覆盖并保留网页草稿。复制、移动目标、恢复操作拒绝覆盖同名文件。删除使用连接器在已授权目录中的恢复库，不是永久删除或 Windows 回收站。权限变更后，旧版本任务不得借用新范围执行。

当前限制：网页编辑上限 15,000 字节；读取回执被截断或摘要不一致时只读。文件摘要、复制、移动和回收有 8 MiB 上限；不支持文件夹递归删除/移动、跨授权根目录移动、任意终端命令或任意程序执行。直接打开仅限允许的普通文档、图片、文本等类型，不执行脚本、可执行文件、网页或宏。更大的文件及复杂软件内部编辑不属于本轮验收结论。

# 通用资源接入与独立电脑连接器

本轮继续在 `fix/native-dialogs-unified-20261026` 开发工作树实施，不部署、推送、重置预览，不操作员工真实设备凭据。

## 1. 员工交付，不再要求取得项目

构建：`pnpm connector:build`。开发机根据明确的模块清单收集本地连接器与已安装的运行依赖，不执行 npm 生命周期脚本；下载固定 Node.js 24.14.1 Windows x64 官方 ZIP 并按官方 HTTPS SHASUMS256 校验，只提取 node.exe 与官方 LICENSE。产物带第三方软件清单、每文件 SHA-256 完整性清单和顶层下载校验值。

输出：`public/downloads/agent-studio-connector-win-x64.zip` 和 `public/downloads/connector-release.json`。生成目录被 Git 忽略。包不包含员工凭据、连接文件、数据库、项目网页源码、Git 或开发环境。便携版运行文件均在完整 ZIP 中，不能只分发一个 CMD。

员工：完整解压 → 双击 `Start-Connector.cmd` → Chrome 打开仅本机可访问的管理窗口 → 从公司工作台生成连接文件 → 在本机选择文件、目录与权限并确认 → 等待真实服务器回执。无需另装 Node.js、pnpm、Git 或获取项目源码；本机仍需 Google Chrome。

现阶段仅 Windows x64 预览便携版，未代码签名，不是 MSI/EXE 安装器；没有托盘、自启动、静默升级或系统服务。不绕过 SmartScreen、公司终端策略或权限确认。正式交付须 IT 审核、签名、版本发布管理及真实干净电脑 UAT。

## 2. 本机图形界面

`local-executor/desktop.mjs` 仅监听 127.0.0.1 随机端口。每次启动生成随机会话令牌，保存在启动 URL fragment 中，客户端移除地址中的 fragment，仅在该本机标签 sessionStorage 保留。API 必须匹配 Host 与会话令牌，所有更改还必须匹配 Origin 和 JSON Content-Type。无 CORS、无任意命令、无路径参数、无远程下载脚本或自动提权。

仅允许：读取当前用户简化连接的非敏感元数据；读取工作台的严格短时连接文件；打开系统文件夹选择器；确认绑定；恢复、停止本进程启动的连接；本机修改授权目录；切换已有浏览器为 Chrome。UI 不收到真实配对码、设备令牌或认证散列回传。外部网页不能借此发起本地操作。

默认只读，目录只能由本机系统选择器返回，不能由工作台输入扩大范围。每次选择产生新的 reviewId；确认期间范围变化则拒绝过期确认。原连接恢复要求指纹一致。目录更换仍使用新根目录别名，原凭据不改变，旧任务不会转移。

子进程使用包内 Node，以 IPC 接收停止请求；不使用 shell。IPC 只发送固定状态枚举，不传设备凭据。只有服务器成功登记工具后的心跳回执才标在线，45秒未收到回执显示需要检查。关闭管理器停止其拥有的子进程，不关闭用户其他进程。

## 3. 站点下载与短时凭证

`ConnectorDownload` 读取同源固定清单，验证版本、架构、文件名、长度、SHA形状，并以HEAD核对文件存在及长度。未发布、404、返回HTML或清单异常时不显示假下载按钮。数字签名状态和文件校验分开表述；校验和不能冒充代码签名。

用户先准备并打开组件，再勾选准备完成后生成五分钟连接文件，避免安装期间过期。旧开发者启动路径降为可展开备用入口。安装包不携带个人连接文件，各员工独立绑定。

当前公司工作台若是 localhost，只有当前电脑可用；同事必须从可达、受信任 HTTPS 入口登录并生成各自连接文件。发布包不会把本机临时预览自动变成公司服务。本轮不部署服务器或启动生产 Worker。

## 4. 资源、插件、工具共用任务导向

资源中心用六种目的组织入口：分析文件、网页、本机电脑、业务服务、Skill方法、AI模型。上传资料、方法和在线服务不要求安装本机组件；只有选择本机操作才出现连接入口。已验证或发现过的连接优先提供核对/复用入口，不重复要求填写密钥。历史发现不等于当前可执行，更不授予Agent角色权限。

资源指导不执行外部调用、不安装插件、不创建账号共享凭据。保留原Agent返回参数及角色/能力上下文。自建HTTP/MCP降到技术人员入口，不能把它们伪装成通用一键安装。

Smithery默认优先已添加的托管连接；明确带入搜索词时仍进入探索列表。供应商要求的账号密钥、OAuth及权限确认不可跳过，也不自动复制管理员密钥给员工。

## 5. 验证

- `tests/connector-distribution.test.mjs`：本机API隔离、严格输入、过期确认、不重放配对、只读默认、下载清单约束、任务导向与资源复用。
- `tests/connector-manager.chrome.mjs`：真实Chrome管理UI、临时PocketBase、真实IPC子进程、停止/恢复、原设备身份保持、四宽度响应式。系统目录选择器用明确测试适配器返回临时文件夹，不操控员工桌面。
- `ops/test-connector-package.mjs`：核对最终下载ZIP、逐文件完整性、排除凭据/数据库，将ZIP解压到项目目录外的临时路径，移除开发Node/pnpm的PATH和NODE_PATH，只用包内Node读取真实临时文件、处理表格、启动真实Chrome访问本地测试页面。
- `pnpm check` 与既有隔离E2E仍须最终通过；专项和分发包测试不能冒充真机UAT或全系统发布合格。

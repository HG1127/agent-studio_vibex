## 员工操作和恢复

多轮任务表单提供缺省未选的“任务结束后保存本次经验或教训”。原提交丢失回复后保留原角色、指令、轮数、方案审核和保存选择，恢复使用相同请求；关闭新的自动保存授权不改变已冻结的选择。

“本次自动保存”显示待完成、已停止、曾保存、来源不可用、后台关闭、保存失败或结果未确认。停止使用二次确认，仅停止新的自动保存；任务仍按原有逐步审批继续。已有内容须在“任务经验与教训”中另行忘记。

停止丢失回复时冻结原任务、原授权摘要和请求编号。导航或能力接口503隐藏状态但保留该请求；恢复后可核对原回执或重新提交同一停止请求。新授权关闭仍允许本人停止和只读确认。退出、Cookie失效或员工切换销毁该员工页面会话；没有浏览器持久化。

主要实现：`PgNativeAutonomousAgentPanel.tsx`、`PgNativeAgentOutcomeMemoryPanel.tsx`、`pgNativeAgentOutcomeMemorySession.ts`。SDK严格核对封闭字段、任务/角色/授权和回执，不接受浏览器提供的所有者、私有正文、治理版本或模型费用授权。

## 服务器边界

051写入需要独立的 `AGENT_STUDIO_PG_AGENT_DERIVED_MEMORY_ENABLED=true` 与 `AGENT_STUDIO_PG_AGENT_DERIVED_MEMORY_APPROVED=APPROVE_DISPOSABLE_PG18_SOURCE_BOUND_MEMORY_ONLY`。

052的独立开关为 `AGENT_STUDIO_PG_AGENT_OUTCOME_MEMORY_ENABLED=true` 与 `AGENT_STUDIO_PG_AGENT_OUTCOME_MEMORY_APPROVED=APPROVE_DISPOSABLE_PG18_OWNER_OUTCOME_MEMORY_ONLY`。Native API还需配置写入、独立Agent执行和来源记忆删除范围；启动检查052、051及人工协议结构。独立Agent Worker单独核对此开关、人工协议和052结构；Workflow Worker不能继承此范围。这些开关不是实际部署、初始化或付费调用许可。

Native接口为 `/api/v2/agent-outcome-memories/<run_id>`、其 `/stop` 和 `/stop-confirm`。读写均使用经过服务器核验的员工Cookie；修改另有Origin/CSRF检查。查询参数、路径/正文任务错配、额外身份字段、Bearer和任意 `X-Rh-User-Id` 均不能提供授权。

Worker复用已核验租约、真实所有者和同一事务。Native治理版本发生变化后，旧自动保存授权失效；停用后重新启用也不恢复旧授权。停止和终态写回按同一任务锁排序。保存或最终记忆审计失败时，回滚记忆而保留原任务终态、私有成果和已发生效果，不重新调用模型。缺少Worker范围时在付费步骤前暂停。

SQL审查校验精确表/列、FORCE RLS、所有者、默认值、约束、触发器、函数正文和执行权限；额外权限及表/列 `WITH GRANT OPTION` 均拒绝。API不能读取Native账号密码或治理列，只能调用返回当前员工治理版本的窄函数。空列ACL直接读取NULL。

公开结果、历史及人工方案/回复继续应用旧运行时四类凭据遮罩，先遮罩再截取；私有终态正文、VM回放、原回执和原摘要不变。来源失效不生成新的完成或记忆证明。

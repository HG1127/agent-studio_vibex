- `agent_engine.pb.js` 的正式业务工具、持久结果、材料、范围授权和请求预算
  已有独立服务端边界。新的阶段执行应调用这条路径，避免复制另一份模型工具循环。
- 内部启动 API 分别验证定时发生实例或研究父节点关联；研究子 Run 还核对

- Run、阶段、问题及父任务请求预算在同一事务内预留，DAG 复用现有图与 Worker。

## 阶段执行协议

阶段采用稳定 `stage_id`，关联 `case_id`、问题 ID、依赖阶段、已保存 AgentSpec
修订、受控输入、预算及验收器。父任务和阶段定义分别保存不可变版本，运行状态
另存。只接受有界无环图；循环或找不到的依赖在模型调用前拒绝。

一次阶段尝试对应一个稳定子 Run ID。父运行、阶段、尝试序号具有数据库唯一键，
先记录启动意图，再调用内部启动入口。网络超时后查询同一 ID，不能新建另一个
子运行来“重试”。父图快照、Spec、员工、问题与预算必须全部匹配。

当前每父节点对应一个子运行；补查创建新的执行版本，按预览决定复用固定产物、
恢复人工复核或启动缺口节点。最新终态版本才能创建后继，幂等请求只产生一个
后继。原运行、回执、事实集与文件不改写。所有权转交仍未实现。
Spec 改动后尚未启动的阶段会明确停止；不静默使用改动后的方案。

执行复用现有 Worker 和 Agent Run。父阶段等待子 Run 时不再次规划、不增加
节点执行次数，也不重复消耗模型额度。审批及用户输入仍在子 Run 中完成，父视图
提供明确入口；父任务不能代替员工批准工具或人工核验。

阶段状态至少区分等待依赖、可执行、运行、等待审批/核验、已交付、部分交付、
失败和取消。模型 `final` 只能结束子执行，不能单独证明阶段验收通过。

阶段产物只存受保护引用：结果 ID、材料片段、固定记录版本、事实集和文件回执。
每次阶段转换、恢复及产物读取重查来源权限。某个前驱撤权后，后继不得继续使用
其缓存摘要；历史状态保留，正文和派生内容隐藏。

## 总额、问题和收尾

请求预留必须在同一事务内同时检查 Run、阶段、问题和父任务总额。任何一层
不足都不能部分扣账后外发。父任务分配给子阶段的额度不能被模型扩大。

收尾额度属于总额的一部分，普通研究调用不能消费它。耗时包含等待；有界收尾
宽限与当前单 Run 规则一致。收尾不得开启新调查，模型输出只可进入未验收草稿；
已有正式记录、缺口和文件按原版本保留。

恢复以持久状态和产物收据判断完成项。补查一个问题时只授权对应问题的答案更新；
共享实体可复用，其他问题答案不被隐式改写。旧报告继续绑定旧事实集。

已实现的追加预算须由真实员工确认预览；Worker 和模型不能自行追加。原根任务
及问题计数持续累计，不因新执行版本重置。全部授权与计划进入追加式审计。
前驱不在补查范围且尚未完成时，默认阻断后继；已明确允许部分输入的阶段会收到
具体缺口。复用输入的版本或权限变化会停止当前执行，需重新预览；共享输入的
自动依赖重建与未知外部效果的核查解除仍待实现。

取消父任务须取消其未完成子运行；外部未知结果保持原副作用日志，不自动重放。
父任务暂停与员工单独暂停子运行应分别记录，恢复父任务不能覆盖后者的决定。

## 采集与语义监测

监测定义绑定对象/问题、明确来源请求、采集 AgentSpec 修订、定时规则、预算和
有效授权。采集复用现有定时发生实例，不能建立绕过原启动验证的平行调度器。

一次检查只有在对应发生实例完成、配置仍匹配、所有已声明请求有真实结果回执、
解析覆盖范围可判定且当前来源权限有效时，才能标为采集完成。网络失败、缺页、
上游截断或未执行请求应标为检查未完成；不能把空结果当作没有变化。

比较对象是固定版本的领域事实和事件，不能比较网页更新时间或报告文字。领域
扩展需登记事实键、身份绑定、有效时间和事件解释；未登记的字段只能作为待复核
差异，不能直接形成业务变化提醒。

需要区分：新增历史材料、真实现任变化、额外兼职、相互冲突、来源失效和来源
不再可读。新增旧报道不构成任职变化；新增角色不证明旧角色结束；未再搜到某人
不构成离职证据。转载/同源报道不能被当作多个独立确认。

基线是不可变快照。采集失败不推进基线；语义待复核的差异不自动成为新事实。
有意义事件按监测版本、前后基线和事实变化哈希去重。无变化保持安静。
通知默认进入应用内待办/事件；对外邮件或消息需要用户明确授权。

## 必须证明的验收

1. 阶段与子 Run 启动之间断线或重启，只出现一个子 Run。
2. 阶段依赖、父总额、问题额度及收尾额度由服务端阻断；模型无法修改。
3. 部分交付后只补缺口，旧事实集和报告字节保持不变。
4. 等待子运行和人工核验不触发重复模型请求。
5. 父取消、员工单独暂停、未知外部结果分别遵守其恢复规则。
6. 断网、遗漏、来源撤权、配置变化均不能显示“检查完成且无变化”。
7. 旧报道、转载、兼职、冲突和缺席的固定反例不产生错误任职变化通知。
8. 完整集成、真实浏览器及授权后的真实模型/员工 UAT 分别保留证据。

这些测试必须落在真实实现上，不能通过预写成功状态、模拟通知文字或仅增加
测试清单来宣告完成。

# Agent Studio — 稳定运行时间线与可验证的最近进展

独立功能分支：fix/run-timeline-scroll-follow-20261026。仅涉及浏览器呈现；不修改 PocketBase、Worker、工具授权、数据库或生产部署。

## 已定位的问题

之前运行中心与详情页在新事件写入时调用 scrollIntoView()。运行中心使用 forceMount 保留非当前标签内容；因此即使用户阅读成果、审批或质量检查，隐藏时间线也可能推动整个页面滚动。用户阅读旧记录时同样会被新事件强制拖到最新。

## 本轮调整

- 两处时间线使用共用 useTimelineFollow 钩子，以独立的最大高度滚动容器展示事件。
- 运行中心仅在“执行过程”标签可见且用户仍在最新记录附近时，跟随新事件；隐藏标签不得滚动。
- 用户主动向上阅读后暂停自动跟随，出现“正在阅读较早记录”和“跳到最新”；新事件数量只作为本地浏览器已载入数量提示。
- 运行详情页沿用同一规则，其独立“实时刷新开关”仍只管理已有服务端轮询逻辑，而不是授权新工具调用。
- 切换运行 ID 会重新初始化本地浏览跟随状态，不能把上一个任务的位置带到下一个任务。
- 中央状态卡新增来自已保存事件的“最近记录：第 N 步 · 工具结果/角色阶段”等摘要。它不包含外部工具参数、数据密钥或自由文本内容，也不会把最近事件当作完成/健康判定。

# 电脑与浏览器：非技术用户操作体验

开发分支 `fix/native-dialogs-unified-20261026`；不操作用户已连接电脑、不重配对、不重启预览、不提交部署。

## 问题与调整

- 配对是账号和设备的一次性绑定，不是执行操作。连接文件已经携带凭证，默认不要求另抄配对码。普通页面已彻底移除手工配对入口和原始参数编辑器；内部仍保留短时、一次性绑定验证。
- 已有在线设备直接复用，未完成的新配对不冒充在线。仅处理资料提供知识库入口，不要求本机组件；本机自动化仍需本人启动/授权。
- Windows 项目新增 `local-executor/start-connect.cmd`。双击使用原生 JSON 文件选择器，保持本机范围确认；不是独立安装器，也不增加后台服务。
- 常用区是中文任务：浏览文件夹、点选文本、打开网页、读当前网页、按授权新建文本。浏览和读取同样单次批准，结果默认是文件列表/正文，不是 JSON。授权截图也使用中文按钮；原始工具编号与参数不再作为使用入口。
- 本地 CLI 支持文件夹窗口/手填具体路径。新选择目录默认只读；读写授权只允许新建，不覆盖。所有绝对路径留在本机配置，网页只通过工具清单看到别名和权限标签。
- `--folder <id>` 更换目录不需要配对，保留设备凭据。换目录使用新别名，旧目录排队操作被执行层拒绝。执行器配置锁阻止新版本同时运行与修改范围。
- 浏览器临时快照独立于资料目录，减少生成的 page.yaml 文件污染用户列表。显示允许访问的网站，未知/未授权地址不冒充可操作。
- 错误提示区分目录当文件、非文本、只读、重复文件、未授权网址和路径越界；任务失败不是连接失败。

## 安全边界

网页不能传入新的本机目录；下载文件结构仍拒绝 roots、apps、desktop 等任意执行配置。受保护目录、整盘、用户主目录、UNC、符号链接/连接点被拒绝。读取时重新核对根目录，禁止硬链接文件、路径穿越与凭证访问。只读不仅是 UI 禁用，运行时和可用工具清单都受约束。新建、换目录、配对与网页访问均有用户确认，不自动批准 Agent 角色权限。

## 接入中断与恢复：继续原登记，不重复创建

- 设备清单增加仅当前账号可见的 `paired` 和 `pairing_expires_ms` 元数据，不返回配对码、凭据或其散列。绑定成功与首个心跳分别判断。
- 状态明确区分待完成配对、未用文件过期、已配对等待启动、在线、离线和撤销。旧服务没有元数据时显示待核实，不猜测成功或过期。
- 尚未配对记录的“继续连接”沿用同一设备 ID；用户重新确认用途和网站后才更新连接文件。旧未用码失效，不新增同名设备。已绑定或已撤销记录的服务端续期拒绝规则不变。
- 向导观测到绑定成功后立即隐藏重新下载/重新生成入口，等待真正心跳与所需能力。后续网络故障不会把已确认绑定降回未配对状态。
- 已有连接优先双击 `local-executor/start-connect.cmd`，在本机管理菜单按名称和服务器选择原连接；恢复前再次明确确认范围。高级命令作为备用方式折叠展示，不安装自启动服务。
- 本机 HTTP 401、404/405、5xx 和超时显示不同下一步；不将所有失败认定为过期，不输出响应正文或凭据，也不自动重放配对。
- 文件与浏览器分视图显示。目录结果标为上次读取的快照；搜索、返回文件列表和切换页签不再发起读取。离线或设备读取故障保留用户输入，但禁止执行，恢复核验后再操作。
- 浏览器故障注入发现原 UI 以整个 catalog JSON 原文作为组件 key：相同权限仅字段/工具顺序变化也会重建表单、丢失文字。现改为规范化工具名与输入权限结构的 key；字段/工具顺序和说明文本变化不影响草稿，真实目录、工具或网站权限变化仍使旧选择失效。专项覆盖离线并重排清单、恢复、503 重试、目录更换和输入保留。

## 本机目录一致性与 Chrome 默认值

当前预览的同版本连接器位于独立 worktree，而不是旧项目根目录。本机开发页通过受限的开发构建常量显示准确启动目录；正式构建为空、远程域名不显示路径。根目录新增 connect-computer.cmd 快捷入口，不自动安装、执行网络下载或提升权限。

新连接、示例配置与无显式选择时默认 Chrome。旧 Edge 连接可经本机确认迁移，保留凭据、目录和网站范围。未安装 Chrome 时在消耗连接凭证前提示，取消迁移和活跃执行器锁均不修改配置。

## 验证范围

`tests/local-device-usability.test.mjs` 测试中文参数校验、原生对话框适配器参数、路径限制、只读/混合目录、同一设备目录更新、活动执行器锁及旧任务失效。原生系统选择器采用受控替身验证调用契约，不在用户桌面自动弹窗。

`tests/guided-connection.chrome.mjs` 使用真实 Google Chrome、临时 PocketBase 和真实浏览器 MCP；本机目录选择由测试代码明确给定，真实文件读取/新建与只读约束均落地检查，覆盖390/768/1440/1780px。没有访问用户工作目录、没有真实付费模型调用。

正式发布仍需原生文件/目录选择窗口的人工作业验收、签名安装包设计及权限治理；不能将当前双击脚本描述为零安装接管电脑。

## API 与权限

`GET /api/agent-runs/recent?archive=1&page=1&status=all&days=all` 使用独立的分页分支；既有 recent/pending 调用不改变。SQL 在查询和计数前约束经现有认证中间件确认的员工身份，稳定排序为 `created DESC,id DESC`。搜索为参数绑定的字面子串；通配符和 SQL 文本不是额外权限。

旧预览后端不返回 `archive_version=1` 时，前端明确显示“仅最近20条、非完整历史”，禁止假装全量统计或虚假翻页。网络/格式失败显示可重试错误，不冒充空列表。数据获取只读，不启动 Worker、调用模型或自动执行。

记录详情和列表请求均校验当前账号、当前记录/查询及请求序号；取消、切换查询后的旧结果不能覆盖新页面。

## 紧凑状态规范

可复用 `WorkspaceEmptyState`：20px 图标、正常字号标题、简短说明、明确下一步；不设固定大高度或营销阴影。空状态属于列表/内容区域，不取代整个工作区。按钮保留至少40px操作高度，真实数据内容不强行压缩。

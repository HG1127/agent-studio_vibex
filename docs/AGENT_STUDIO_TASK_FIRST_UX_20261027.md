# Agent Studio：任务导向体验迭代 · 2026-10-27

## 本次目标与边界

在已有 UI/UX 修改上继续减少重复选择、保存、跳转与无关表单；不是全系统推倒重建。本次代码只位于独立 worktree `harness-design-20261021` / `fix/native-dialogs-unified-20261026`。没有推送、合并、生产部署、真实数据库修改或付费模型调用。前期已有更改全部保留。

## 已落地

### 1. 普通员工个人账号与管理员工彻底分流

- `/account` 为所有已登录用户开放，只请求本人 `/api/studio/me`；支持原有本人密码修改流程。
- `/staff` 仍由 AdminGate 和后端独立管理员检查保护，不因为普通员工需要改密码而放开员工清单。
- 账号菜单始终提供“我的账号与安全”；仅管理员额外显示“员工与权限”。
- 独立组件 key 防止在个人设置和团队管理之间复用旧的表单/标签状态。

### 2. 个人待办、公司统计使用正确口径

- 原 `/internal-overview` 改名“我的任务与待办”，移动到工作台；此接口原本就是按当前员工隔离，不能称为公司总览。
- 真正的公司统计留在管理中心“公司运行”，使用 `/api/studio/company/overview`；前端核验 `scope=company_metadata_only`。
- 修正监控链接为 `/tool-hub?view=monitor`；外部调用核查入口使用 `view=activity`，不再落入电脑绑定视图。

### 3. 管理中心由长页改成三种明确视图

- 默认“待我审批”，仅显示已被员工主动委托的步骤；支持按任务、员工、工具搜索，按到期时间排序，已加载记录每页展示 10 项（不是声称服务器全量分页）。
- “公司运行”按需请求公司指标，用响应式员工聚合卡替代 720px 固定宽表。总待审批数与本人有权审批数明确区分。
- “我的委托”只读取当前用户待审批任务；选择负责人不再默认第一位管理员，必须显式选择并填写审核说明。
- `/approvals` 对普通员工开放本人委托，不请求公司管理接口，即使查询参数写 `view=company` 也不会切换权限范围。
- 切换视图不一起请求所有接口；失败时隐藏旧数据，不能把服务不可达显示为“没有待办”。保留服务端指纹核验、单步授权、过期检查与最终决策确认。
- 本轮没有虚构“处理记录”页；完整审计浏览视图仍是后续事项。

### 4. 创建向导：保存并继续

- 第二步主操作变为“保存并继续：连接资源”，保留次要的“仅保存草稿”。内嵌编辑器不再重复展示保存主按钮。
- `agentPlanContentIssues` 共用现有结构校验；未填完整的目标/范围/交付物/完成标准仍不允许前进。
- 保存返回明确的记录 ID 与当前草稿一致性；网络失败、并发冲突、保存期间修改、切换 Agent 或离开页面时均不能错误推进。
- 一次点击不发起模型、工具运行或发布。

### 5. 试跑页按任务状态呈现

- 没选 Agent 不显示无效的任务启动表单；选中后才显示输入。
- 已有运行时把启动表单改为本次任务摘要和查看完整说明，先展示人工待办/过程/成果。结束后用“基于此 Agent 发起新任务”重新进入输入。
- 未显式选设备、也没有 `local_computer` 的 Agent 默认不展开本地电脑选择器，但保留“为本次任务使用电脑（可选）”入口；展开和选择设备不会运行或自动批准。已有电脑工具/明确选定设备时直接显示选择器。历史任务仅显示运行摘要，不提供会误导用户修改历史设备的输入表单。
- 运行中默认进入执行过程，结束后默认展示成果；用户仍可主动选择其他视图。
- 运行标签使用响应式两/四列，避免窄屏横向挤压。

### 6. 执行资源中心不是五道必经手续

- 原五个“步骤”改为同级可直接切换的资源视图：已接入能力、我的电脑、测试工具、调用记录、运行监控。
- 只有电脑操作才配对设备；添加工具后仍要真实试调及明确角色授权。
- 兼容原路由和 Agent 返回上下文，不改既有调用权限。

### 7. Skills 以已存方法为主，导入按需

- 现有列表和版本审核占据主体；点击“导入 Skill”才打开导入对话框。
- 导入成功关闭对话框并选中真实待审核版本；未自动审核、绑定角色或运行脚本。
- 切换导入方式或关闭时，只有存在未提交内容才确认清空。
- 旧版已审核而新版未审时显示“新版本待审核”，不以笼统的“已审核”掩盖状态。
- 区分正在加载、查询失败、没有方法和搜索无匹配的空状态。

### 8. 可访问性

- Agent 目标、任务范围与列表条目补齐可访问名称。
- 个人安全页面包屑指向正确空间。
- 账号、审批等与 Agent 编辑无关页面不出现悬浮 Agent 编辑入口。

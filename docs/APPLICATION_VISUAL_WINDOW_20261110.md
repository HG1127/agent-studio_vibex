## 真实反馈与复现

用户在安装版 EXE 选择 MiniMax-M3.1-Flash 后，任务 `17a1kx8jdu1nlvc`

该字段未在原动作 Schema 中声明，严格参数检查在输入之前拒绝请求。
没有执行该次点击，更没有输入或发送业务任务。验收不操作该用户任务。

## 本阶段要求

- `apps.act_visual` 接受可选的字符串 `window`，并向模型明确发布该可选字段。
- 如提供，必须是1–20位十进制窗口编号，并精确等于当前观察凭据绑定的窗口。
- 参数不得选择或替换目标；原观察记录中的窗口、PID、位置、尺寸继续决定本机操作。
- 省略该字段的旧调用保持兼容。其他未知字段、错误类型及不匹配窗口继续拒绝。
- 保持本人应用授权、截图许可、30秒一次性凭据、原本机确认、坐标边界及禁止不确定副作用重放。
- 输入仍限制为单段文字；发送或按键仍是独立操作。不自动修剪、丢弃或猜测模型参数。
- 必须先由实际安装版 EXE 发起公开调研，并取得完整结果及来源，才算 WorkBuddy 闭环验收通过。

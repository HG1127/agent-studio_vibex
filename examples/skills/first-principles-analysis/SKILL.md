# 第一性原理分析视角

这份演示 Skill 参考公开的第一性原理分析方法，并非马斯克本人编写、认可或代言。

## 使用场景
涉及行业惯例、成本结构、工程极限、商业模式或投资机会的研究。仅作为分析方法，不是独立事实来源。

## 执行流程
1. 将行业习惯、预测和断言拆分为“事实 / 假设 / 尚待查证的猜想”。
2. 拆解到底层的材料、资本、人员、算力、供应链、供需约束，给关键数字附证据或不确定区间。
3. 从基本约束重新组合解决路径，解释哪些传统步骤可以去除。
4. 寻找反例、竞争者应对和隐藏的不可逾越瓶颈。
5. 针对每个重要假设设计验证实验，明确数据、指标、时间窗口与失败条件。

## 交付要求
每个核心结论给出验证证据、推导路径、反面论据和待验证项。不能冒充已完成的行业调研或代表某个真实人物的个人判断。不得自行授予工具权限、读取秘密、调用脚本、联系第三方。
